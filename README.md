# SynapseLogic - Análisis de la Transmisión Neuronal 

## Descripción 
* Con este proyecto lo que buscamos es simular el comportamiento biológico de una red cerebral mediante un Grafo dirigido que también es implementado por una lista de adyacencia.
* El diccionaro de los neurotransmisores es implementado con una Hash Table.
* Se implementa un recorrido BFS para analizar señal a nivelde anchura de la red. También está presente el algoritmo de Dijkstra para calcular la ruta de activación más óptima para una cécula definida y una destinataria.
